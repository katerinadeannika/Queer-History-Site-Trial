## Editorial rules

- Preserve each manuscript chapter's complete substantive text.
- Reformat headings, production labels, block quotes, citations, and lists only as needed for HTML reading.
- Never substitute a condensed interpretation for the chapter text.
- Add addendum material only in its correct decade and label it `Supplemental insertion`.
- Where the two addendums conflict, prefer the newer v2 addendum pending source review.
- Use evidence grades: A documented partnership; B strongly supported intimacy; C documented attraction or emotional attachment; D rumour or disputed interpretation.
- Keep every media asset as a citation-backed external reference until a rights-cleared local file exists.
